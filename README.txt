Reda Accounting - نسخة تجريبية أولية
المحتويات: تطبيق ويب تقدمي PWA يعمل بعد استضافته على رابط HTTPS.
مهم: فتح index.html مباشرة لا يتيح التثبيت كتطبيق PWA؛ يجب رفع المجلد إلى استضافة HTTPS (مثل GitHub Pages).
بعد النشر: افتح الرابط في Chrome على Android > القائمة ⋮ > تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
البيانات تحفظ محليًا في المتصفح على نفس الجهاز. استخدم زر تصدير نسخة احتياطية بانتظام.
هذه نسخة أولية: لا تحتوي بعد على صلاحيات مستخدمين أو مزامنة سحابية أو دفتر أستاذ وميزان مراجعة تفصيلي.
